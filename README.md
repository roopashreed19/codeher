Completed Features:
1. Question Generation by Difficulty
Students can upload their study material or textbooks, and the platform automatically generates subjective questions categorized into Easy, Medium, and Hard. This enables personalized practice and helps build confidence progressively.

2. AI Chatbot for Doubt Solving
An intelligent, Gemini API-powered chatbot provides real-time, subject-specific doubt-solving based on the uploaded content—offering 24/7 academic support similar to a personal tutor.

3. Performance Analysis
Students can input their test scores, and the system calculates their overall percentage and highlights weak subjects based on performance. This gives them clear, actionable insights to improve strategically.

4. Mock Test Generation
The platform now supports full-length mock test creation using previously generated questions—mimicking real exam environments and enhancing preparation through simulation.

5. Dopamine Reels Section
A unique feature that helps students stay motivated and avoid burnout—through quick, productivity-focused reels that provide mini dopamine boosts without the distraction of mainstream social media.
